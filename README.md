# 五行槍神錄 3D · Wuxing Strike

**▶ 立即遊玩：https://supercoder592.github.io/guns/**（2D 經典版：[classic.html](https://supercoder592.github.io/guns/classic.html)）

3v3 連線寫實風五行屬性槍戰（Three.js + PeerJS，純靜態部署於 GitHub Pages）。

## 玩法
- **開房制連線**：房主建房取得 5 位房號 → 隊友輸入房號加入（P2P 直連）；也可單人開戰。**房間等待畫面可隨時更換屬性**，全員即時同步。房主可切換**「人機補位：開/關」**（關閉適合 1v1 單挑）；**同隊玩家可點擊我方空位，指定該 AI 士兵的屬性**（🎲=隨機）。
- **屬性手雷**：`G` 鍵（觸控「雷」鈕）投擲，每命兩顆；拋物線＋彈跳物理，爆炸依屬性附加效果（火灼燒／水緩速／冰疊凍／雷土震懾／木纏繞／暗致盲／風擊飛／光＝治療彈回復我方），落點留下大型屬性區域，土雷還會轟出岩掩體。
- **三對三**：赤焰隊 vs 蒼瀾隊，**開戰時人數不足自動由 AI 士兵補齊**，玩家中途離線也由 AI 接管。
- **賽制**：110 分鐘團隊死鬥；擊殺 +100 分、連殺加成、爆頭加分，時間到比總擊殺。
- **十行系統**：十名角色（金木水火土＋冰雷風暗光），相剋傷害 ×1.7 / 被剋 ×0.6；子彈附帶屬性效果（火灼燒、水緩速、木吸血、金必爆＋跳彈、土震懾、冰疊凍冰封、雷連鎖閃電、風擊退、暗蝕明致盲、光光速彈＋淨化爆發）；土系 E 技能可築岩牆掩體、暗系可匿蹤、光系可設治療聖域。
- **子彈改造戰場**：子彈落點依屬性改變場地（觸發率隨槍威力）——火海、霜凍地、岩石掩體、荊棘叢、碎刃區、冰封地、雷場、亂流域（推開敵人）、暗幕（致盲＋遮蔽 AI 視線）、聖域（治療我方）；AI 的子彈同樣會改造場地。
- **十行反應**：水/冰澆火 → 蒸汽雲＋額外傷害；火燒藤蔓 → 爆燃 AoE；水浸土牆 → 泥沼；雷擊受寒者 → 超導全場連鎖；風助火勢蔓延、風＋冰 → 風雪暴、罡風吹散暗幕；光暗相剋互滅、光淨化蝕明觸發聖光爆發。
- **物理與可互動場景**：碎片/彈殼物理彈跳、紅色油桶可打爆（範圍傷害＋衝擊波擊飛＋連鎖引爆＋留下火場）。
- **CS 式槍感**：環境反射槍身質感、視角慣性槍模搖擺、移動起伏、換槍舉槍/換彈下壓動畫、動態擴張準星、疾跑 FOV、擊殺確認（骷髏＋分數＋確認音、爆頭「叮」）。
- **屬性演出**：十屬性專屬命中爆發、狀態特效（著火/冰晶封體/藤蔓纏繞/暈眩金星）直接顯示在角色身上、大招閃屏染屬性色；雷大招天幕壓暗＋天際巨型電弧、風大招擎天龍捲捲飛碎屑。
- **士兵模型**：分節四肢行走擺動、戰術背心彈袋、頭盔護目鏡、背包屬性徽章、隊伍臂章、死亡倒地動畫。
- **場景細節**：高解析地面（裂縫/油漬/色斑）、粗糙度變化、反光水窪、外圈雜草叢。
- **中二大招**：能量集滿按 Q，全螢幕演出（萬刃殲滅砲（8 秒加特林、貫穿掩體）、世界樹之怒、滄海萬川歸一、鳳凰劫、山崩地裂、千里冰封、九天玄雷、九霄龍捲、永夜降臨、審判之曦）。

## 操作
`WASD` 移動 · 滑鼠射擊 · 右鍵開鏡（狙擊）· `Shift` 疾跑 · `Space` 跳躍 · `R` 換彈 · `1-5` 換槍 · `E` 技能 · `Q` 大招 · `G` 屬性手雷 · `Tab` 計分板

## 部署
推送到 `main` 或開發分支會由 GitHub Actions 自動同步至 `gh-pages` 重新部署。
