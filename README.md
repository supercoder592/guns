# 五行槍神錄 3D · Wuxing Strike

**▶ 立即遊玩：https://supercoder592.github.io/guns/**（2D 經典版：[classic.html](https://supercoder592.github.io/guns/classic.html)）

3v3 連線寫實風五行屬性槍戰（Three.js + PeerJS，純靜態部署於 GitHub Pages）。

## 玩法
- **開房制連線**：房主建房取得 5 位房號 → 隊友輸入房號加入（P2P 直連）；也可單人開戰。
- **三對三**：赤焰隊 vs 蒼瀾隊，**開戰時人數不足自動由 AI 士兵補齊**，玩家中途離線也由 AI 接管。
- **賽制**：110 分鐘團隊死鬥；擊殺 +100 分、連殺加成、爆頭加分，時間到比總擊殺。
- **五行系統**：五名角色（金木水火土），相剋傷害 ×1.7 / 被剋 ×0.6；子彈附帶屬性效果（火灼燒、水緩速、木吸血、金必爆、土震懾）；土系 E 技能可築岩牆掩體。
- **中二大招**：能量集滿按 Q，全螢幕演出（萬刃歸宗、世界樹之怒、滄海萬川歸一、鳳凰劫、山崩地裂）。

## 操作
`WASD` 移動 · 滑鼠射擊 · 右鍵開鏡（狙擊）· `Shift` 疾跑 · `Space` 跳躍 · `R` 換彈 · `1-5` 換槍 · `E` 技能 · `Q` 大招 · `Tab` 計分板

## 部署
推送到 `main` 或開發分支會由 GitHub Actions 自動同步至 `gh-pages` 重新部署。
